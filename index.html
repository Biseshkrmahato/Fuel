🔗 Google Drive Sync

Sign in with your own Google account and FuelIQ will keep a backup file (fueliq-data.json) in your Drive, updated automatically whenever you log an entry. FuelIQ only ever touches the one file it creates — nothing else in your Drive is visible to it.

This app has no server, so it needs an OAuth Client ID from your own free Google Cloud project to talk to Drive:
1. Go to console.cloud.google.com/apis/credentials (create a project if you don't have one).
2. Enable the Google Drive API under "APIs & Services".
3. Configure the OAuth consent screen (External, and add your own email as a test user).
4. Create an OAuth client ID → Application type Web application.
5. Under "Authorized JavaScript origins", add the exact origin this page is opened from (e.g. ).
6. Paste the Client ID above and click Connect.
